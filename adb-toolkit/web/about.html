使用说明

ADB 工具箱是 Termux Ultra 的插件，提供完整的 ADB 管理功能。

  • 设备管理：在主页查看已连接的 ADB 设备，点击设备查看详情
  • 远程连接：在远程 ADB 页面输入设备 IP 和端口，通过网络连接
  • 快捷命令：预置了常用的系统信息、应用管理、日志命令
  • 自定义命令：在自定义标签页输入任意 ADB 命令执行
  • 端口转发：添加和管理 ADB 端口转发规则

权限说明

  • H5_WEBVIEW — 显示插件 H5 页面界面
  • TERMUX_SESSION_ACCESS — 执行 ADB 和 Shell 命令
  • FILE_SYSTEM_READ — 读取系统文件信息
  • INTERNET_ACCESS — 远程 ADB 网络连接
