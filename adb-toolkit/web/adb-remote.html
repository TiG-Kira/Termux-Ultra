远程 ADB 连接步骤

开启 ADB 无线调试
在设备上进入「开发者选项」→ 打开「USB 调试」和「网络调试」（或「无线调试」）
获取设备 IP 地址
在设备的「设置 → WiFi」中查看连接的网络 IP 地址
确认设备端口
设备显示的端口号可能不是 5555，以设备实际显示的为准
在本工具输入 IP 和端口
在上方「连接」标签页输入设备的 IP 地址和端口号
点击「连接设备」
等待 ADB 建立连接，首次连接需要在设备上确认授权
开始使用
连接成功后，在主页和设备标签页查看设备详情，执行远程命令

注意事项

🔹 同一局域网：确保本设备和目标设备连接在同一 WiFi 网络

🔹 防火墙：确保设备防火墙允许 ADB 调试端口的入站连接

🔹 首次授权：首次连接时，目标设备会弹出授权对话框，需勾选「始终允许」

🔹 安全风险：请勿在公共网络或不受信任的网络上开启无线调试

🔹 端口冲突：如果 5555 端口被占用，可以尝试使用其他端口

故障排除

连接失败（Connection refused）

→ 确认设备已开启无线调试功能，端口号正确

设备显示 offline

→ 执行「断开连接」后重新连接，或重启 ADB 服务

连接超时

→ 使用网络检测工具测试 IP 连通性，检查路由器隔离设置

未授权（unauthorized）

→ 在目标设备上查看是否有授权提示，点击「允许」
