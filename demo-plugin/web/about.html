关于本插件

这是 Termux Ultra 官方提供的示例插件，用于演示插件系统的完整功能和接入方式。

  • 展示 H5 多页面界面的组织方式
  • 演示 JS Bridge API 的调用
  • 提供资源卡片和技能卡片的配置示例
  • 说明 System Prompt 的注入机制

H5 文件结构规范

插件 H5 页面需遵循以下文件结构要求：

  • 所有 H5 文件（HTML、CSS、JS、图片）放在插件包根目录下
  • manifest.json 中的 entry 路径相对于插件包根目录
  • 例如 web/index.html 表示根目录下的 web 文件夹内的 index.html
  • h5Home.entry 指定主页入口，pages[].entry 指定子页面入口
  • 所有 entry 指向的文件必须在插件安装时存在，否则会报错

JS Bridge API

  • getPluginInfo() — 获取插件元信息
  • getConfig() / setConfig(k,v) — 读写插件配置
  • exec(cmd) — 执行终端命令
  • readFile(path) — 读取插件内文件
  • openUrl(url) — 打开外部链接
  • toast(msg) — 显示 Toast 提示
  • getDeviceInfo() — 获取设备信息
  • finishPage() — 关闭当前页面
